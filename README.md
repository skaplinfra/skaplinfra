# 🏗️ techinfra @ skapl.com

Welcome to the **techinfra** repository!

This repository is maintained by the skapl.com team and is dedicated to handling all infrastructure-related tasks, specifically:

## 🚀 Purpose

- **Website Deployment:**  
  Configuration and automation scripts for deploying organization websites to staging and production environments.

- **Database Connection Establishment:**  
  Secure and standardized setup for connecting backend services to our organization's databases.

## 📁 Contents

- Deployment scripts and workflows (e.g., Docker, GitHub Actions)
- Configuration files for cloud providers
- Secrets and credential management (excluded from repo but documented)
- Database connection templates and examples

## 🛡️ For Organization Members

If you are working on a project that involves:
- Spinning up a new web app
- Setting up database access
- Configuring environment variables or deployment pipelines

Please refer to this repository before starting, and contribute improvements or updates as needed.
